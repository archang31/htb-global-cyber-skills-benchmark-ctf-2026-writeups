# Security and Responsible Use

## Authorized Research

All content in this repository was produced during the Hack The Box Global Cyber Skills Benchmark CTF 2026: Project Nightfall, a time-limited, authorized Capture the Flag competition. Every technique described was applied exclusively against challenge infrastructure operated by Hack The Box for competitive purposes.

## Educational Purpose

The writeups and scripts in this repository are published for educational and defensive security purposes:

- To document attack techniques so that defenders can recognize and mitigate them
- To explain the root causes of vulnerabilities in a structured, reproducible way
- To contribute to the public knowledge base of CTF methodology

## Responsible Use

The techniques described in this repository include vulnerability exploitation, cryptographic attacks, binary reverse engineering, forensic analysis, and cloud security research. These techniques are legal and ethical only when applied to systems you own or have explicit written authorization to test.

Do not apply any technique described here against:

- Systems you do not own
- Systems without explicit written authorization from the owner
- Production infrastructure of any kind outside an authorized engagement

## No Sensitive Data

Real flags, private keys, session tokens, credentials, and environment-specific values have been removed or replaced with placeholders. If you believe any sensitive value has been inadvertently published, please open an issue in this repository.
